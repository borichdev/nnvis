# NNVis — Визуализация обучения нейронных сетей

Школьный проект учащегося 10 класса проекта «Математическая вертикаль» (Москва).

Приложение для наглядной интерактивной визуализации архитектуры, весов, процесса обучения и границы решений (decision boundary) простейших нейронных сетей (начиная с задачи XOR).

## Стек технологий и библиотеки

* **[PyTorch](https://pytorch.org/) (`torch`)** — математическое ядро, построение полносвязных слоев, функции активации (Tanh, Sigmoid), расчет градиентов (`autograd`) и оптимизация весов.
* **[PySide6](https://wiki.qt.io/Qt_for_Python)** — десктопный графический интерфейс на базе Qt. Обеспечивает элементы управления (параметры обучения, функции активации) и вынос вычислительного цикла в отдельный поток (`QThread`) для плавной отрисовки в реальном времени.

## Структура проекта

* `model.py` — определение архитектуры нейронной сети на PyTorch.
* `trainer.py` — фоновый поток обучения (`QThread`), отправка метрик и весов через сигналы Qt.
* `main_window.py` — главное окно приложения, элементы управления и виджеты визуализации.
